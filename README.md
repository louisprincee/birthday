# 给你的日本旅行

一份可离线打开的生日旅行纪念册。页面和图片都保存在本项目中；联网仅用于 GitHub Pages 首次发布。

## 本地查看

直接用浏览器打开 `index.html` 即可。风景图片存放在 `assets/`，不需要联网加载。

## 发布到 GitHub Pages

把项目推送到 GitHub 仓库的 `main` 分支后，仓库中的 GitHub Actions 会自动发布网页。首次发布前，请在仓库的 **Settings → Pages → Build and deployment** 中将来源设为 **GitHub Actions**。发布完成后，网址通常是：

`https://<GitHub 用户名>.github.io/<仓库名>/`

## 图片来源

风景照片来自 Unsplash，已下载到 `assets/`，网页运行时不会请求远程图片。
